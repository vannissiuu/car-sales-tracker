## 六、已知局限

1. **`manufacturer_to_brand` 里"长城汽车"/"上汽集团"/"奇瑞捷豹路虎"三个值是哨兵值，不是真实品牌名**。在当前数据里它们从不会被实际用到（因为 `model_to_brand` 100%覆盖了这三家的全部现有车型，完整解析验证过"回退到厂商原值 0 行"）。它们存在的唯一作用是：如果这三家厂商未来推出 `model_to_brand` 里还没收录的新车型，resolve会明显地把它归类成一个"假品牌"（值等于厂商原名），提醒维护者这里需要更新，而不是被悄悄地、错误地合并进现有的某个子品牌（比如把未来一款新的魏牌车型误判成"哈弗"）。**这份字典需要在这三家厂商每次发布新车型时手动补充 `model_to_brand`**，否则品牌视角会出现"长城汽车"/"上汽集团"/"奇瑞捷豹路虎"这样不属于任何真实品牌的杂项条目。"蔚来"例外——它的兜底值恰好等于其主品牌名，新车型即使暂时没进 `model_to_brand` 也大概率被正确归为"蔚来"（除非是乐道/萤火虫的新车）。

2. **`_unresolved_notes`（6条）涉及的车型/厂商，按最保守方式回退处理，不代表100%确定**：北汽L6H（回退到"锐胜"）、示界06（回退到"纳米"）是两个明确"可能不准"的车型级空白；科莱威、爱跑、花仙子的品牌独立性把握也略低于其他条目，但已经给出了具体归类而非留白，供用户按需复核。

3. **车型级拆分只覆盖了本次识别出的8家"一厂多品牌"厂商**（长城汽车/蔚来/上汽集团/奇瑞捷豹路虎/星途/北京汽车制造厂/江汽集团/江铃集团新能源）。`manufacturer_to_brand` 里其余109家厂商目前没有再逐条排查是否存在更细粒度的多品牌情况——比如个别厂商内部可能存在体量很小、我们未特别留意的子系列命名差异。如果后续在品牌视角看板上发现某个品牌的车型列表里出现"眼熟但品牌不对"的车型，大概率就是这类未被发现的细节，建议看板上线后留一个"按车型反查厂商"的排查通道。

4. **"图腾"式的兜底机制本身要求维护纪律**：`model_to_brand` 优先于 `manufacturer_to_brand` 的解析顺序，意味着这份字典的正确性会随时间推移依赖持续维护（尤其是8家多品牌厂商），而不是一次性完成后就可以永久不变。建议看板加一个数据质量检查：定期跑一遍"新出现的车型是否命中了 manufacturer 级的哨兵值兜底"，作为提醒更新字典的信号。
