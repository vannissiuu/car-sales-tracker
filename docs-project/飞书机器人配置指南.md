# 飞书推送配置指南

看板每个月自动更新数据后，会往你指定的飞书群里发一张卡片，提醒你和同事去看。
你不需要懂技术，跟着下面的步骤点一遍就行，大概 10 分钟。

一共四步：

1. 建一个飞书群（如果已经有想用的群，跳过这步）
2. 在群里加一个"自定义机器人"，拿到一个网址（webhook 地址）
3. 把这个网址存进 GitHub 的 Secrets（重点：**不能**直接写进代码里）
4. 选一下安全设置

---

## 第一步：建一个飞书群

1. 打开飞书 App（手机或电脑都行）。
2. 点左上角的 **"+"** 号，选择 **"创建群聊"**。
3. 给群起个名字，比如"汽车销量看板通知"，把需要看到通知的同事拉进来（也可以先只拉自己，以后再加人）。
4. 点 **"创建"**，群就建好了。

如果你已经有一个日常用的群，也可以直接用那个群，不用单独建。

---

## 第二步：给群加一个自定义机器人，拿到 webhook 地址

这一步是关键，只需要是群主或群管理员就能做，**不需要公司的飞书管理员权限**。

1. 打开你刚才建的那个群。
2. 点群右上角的 **"..."**（更多）图标，或者点群名称打开 **"群设置"**。
3. 找到 **"群机器人"**（有的版本叫 **"机器人"**），点进去。
4. 点 **"添加机器人"**。
5. 在机器人列表里找到 **"自定义机器人"**，点它。
6. 给机器人起个名字，比如"销量播报"，可以随便传个头像，然后点 **"添加"**。
7. 接下来会看到一个 **"安全设置"** 的页面 —— 这一步先别关，翻到本指南最后的"第四步"，选好设置再继续。
8. 设置完安全选项后，点 **"完成"**，页面会显示一个很长的网址，类似这样：

   ```
   https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```

   这一串网址就是 **webhook 地址**。点旁边的 **"复制"** 按钮把它复制下来。

   **这个网址非常重要，等同于"谁拿到它，谁就能往这个群发消息"**。不要把它发到公开的地方（比如发到群里聊天、贴到网页上），也不要真的写进代码文件里。下一步我们会把它安全地存起来。

---

## 第三步：把 webhook 地址存进 GitHub Secrets

我们的看板代码是放在 GitHub 上的**公开仓库**（谁都能看到代码内容）。所以 webhook 地址绝对**不能**直接写在代码文件里 —— 那样任何人都能看到，都能冒充你往群里发消息。GitHub 提供了一个专门存"密码类"信息的地方，叫 **Secrets**，存在这里的内容外人看不到，代码运行的时候会自动读取。

1. 打开你的仓库网页（浏览器里访问 `github.com/你的用户名/仓库名`）。
2. 点仓库页面上方的 **"Settings"**（设置）标签页。
   - 如果没看到这个标签，说明你可能不是这个仓库的所有者/管理员，需要请仓库拥有者来做这一步。
3. 左边菜单栏找到 **"Secrets and variables"**，点开它，再点 **"Actions"**。
4. 点右上角绿色的 **"New repository secret"**（新建仓库密钥）按钮。
5. 会出现两个填空：
   - **Name**（名称）：填 `FEISHU_WEBHOOK`（必须一字不差，全部大写，中间是下划线）
   - **Secret**（内容）：把第二步复制的那一长串 webhook 网址粘贴进去
6. 点 **"Add secret"**（添加密钥）保存。

如果你在第四步选择开启了"签名校验"（推荐），还需要再重复一次上面的操作，多存一个：

   - **Name**：`FEISHU_SECRET`
   - **Secret**：签名校验对应的那串密钥（在第四步会说明在哪里找）

另外还需要存一个看板网址，方便卡片上的按钮跳转：

   - **Name**：`DASHBOARD_URL`
   - **Secret**：你看板页面的网址（比如 GitHub Pages 的地址）

存完之后，这个页面的列表里会出现 `FEISHU_WEBHOOK`（以及 `FEISHU_SECRET`、`DASHBOARD_URL`）几行，**内容是看不到的**（这是正常的，Secrets 存进去之后连你自己都看不到原文，只能覆盖重存），只要名字对得上就行。

**再强调一次**：千万不要把 webhook 网址直接粘贴到 `.py`、`.yml` 这些代码文件里再提交上去 —— 仓库是公开的，等于把地址公布给全世界，别人可以拿它往你的群里乱发消息，或者干扰整个通知功能。存 Secrets 是唯一安全的做法。

---

## 第四步：安全设置怎么选

在第二步"添加机器人"的最后一屏，飞书会让你选安全方式。可以同时选多个，下面说说各自的作用和取舍，帮你判断怎么选：

### 方式一：自定义关键词（最简单，建议至少开这个）

要求飞书机器人发的每条消息里，必须包含你设定的某个关键词，否则飞书会拒绝发送。

- **优点**：设置最简单，点几下就好，能防止别人拿着你的 webhook 网址发送和销量播报无关的消息（因为他们不知道要带哪个关键词）。
- **缺点**：如果消息里忘了带关键词，会发送失败。
- **建议**：填一个类似 **"销量"** 或 **"销量播报"** 的词。本指南配套的推送代码，卡片标题里天然就带"销量"两个字，不用额外改代码。

### 方式二：IP 白名单

只允许从你指定的服务器 IP 地址发消息过来，其他 IP 一律拒绝。

- **优点**：安全性最高，即使 webhook 网址泄露，攻击者的电脑 IP 不在白名单里也发不了消息。
- **缺点**：**不建议用在这个场景**。因为我们的推送是通过 GitHub Actions 运行的，GitHub 每次运行代码用的服务器 IP 是不固定、会变的，你没法把一个固定 IP 填进白名单。选了这个反而会导致以后所有通知都发送失败。

### 方式三：签名校验（加签）—— 推荐，安全性和方便程度都不错

飞书会给你一串"密钥"，每次发消息时，代码要用这串密钥现算一个"签名"一起发过去，飞书验证签名对不对，不对就拒绝。

- **优点**：即使 webhook 网址被别人看到了，没有这串密钥也没法冒充你发消息，安全性接近 IP 白名单，但是不受"服务器 IP 会变"的限制，很适合 GitHub Actions 这种场景。
- **缺点**：需要多存一个 Secret（`FEISHU_SECRET`，见第三步）。
- **在哪里找这串密钥**：勾选"签名校验"后，飞书会在旁边直接显示一串字符（通常以 `xxxxxx` 或类似形式展示），把它复制下来，按第三步存成 `FEISHU_SECRET` 这个 Secret 就行。本指南配套的代码已经支持自动识别并计算签名，不用你再做别的事。

### 我们的建议

对这个"月度销量播报"场景，建议：**同时开启"自定义关键词"和"签名校验"**。两个都设置好之后，即使 webhook 网址不小心泄露出去，别人也没法拿它乱发消息或者干扰你的群。IP 白名单不用管，跳过就行。

---

## 完成后怎么确认好用了

配置都存好以后（`FEISHU_WEBHOOK`，以及可选的 `FEISHU_SECRET` 和 `DASHBOARD_URL`），下次数据自动更新跑完，飞书群里就会自动收到一张卡片：数据正常时是绿色的"更新成功"卡片，抓取出问题时是红色的"同步异常"卡片。如果配置没生效（比如 Secret 名字拼错了），推送这一步会自动跳过，**不会**影响销量数据本身的正常更新，你可以回来检查一下 Secrets 里的名字是不是跟本指南写的完全一致（`FEISHU_WEBHOOK` / `FEISHU_SECRET` / `DASHBOARD_URL`，全大写，下划线不能漏）。
