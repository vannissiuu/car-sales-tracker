# 海外销量视角 —— 调研记录与搁置决定

> 调研时间：2026 年 8–9 月
> 状态：**已评估，决定暂不实施**
> 本文档的作用：把结论**和它的依据**一起留下，避免半年后有人重新提出同一个想法时，从零再查一遍。

---

## 一、结论

**不做。** 不是因为技术上做不到，是因为**能自动化拿到的数据只覆盖中国车企海外销量的约 7–8%**，而做出来的东西会被当成"海外销量"来读。

一句话概括风险：**做出来的东西配不上它会被赋予的解读。**

### 触发重启的两个条件（满足任一）

1. **要回答的问题变了**。如果关心的不是"海外总量"，而是"中国品牌能否在成熟市场立住脚"，那已探明的这批市场是个不错的观察窗（西班牙 10.3%、澳洲 15.0%、新西兰 12.6%、泰国 22.2% 的份额曲线有独立信息量）。**但那个功能必须叫「中国品牌在成熟市场的渗透」，不能叫「海外销量」。**
2. **俄罗斯 + 中东 + 拉美的数据能拿到**。现实中基本等同于采购一份 MarkLines 或 JATO 订阅。届时覆盖率可从 7% 跃升到大部分，功能才真正成立。本次未查询这两家的定价。

## 二、覆盖率测算（决策的核心）

### 分母：三种口径，必须挑对

| 口径 | 2025 全年 | 问题 |
|---|---|---|
| (a) 中汽协·汽车出口总量 | **832 万辆**（同比 +30%） | 含商用车，含特斯拉中国/宝马/沃尔沃中国工厂出口的外资品牌车 → **把比例算低** |
| (b) 中国品牌乘用车出口 | **491 万辆**（燃油 287 万 + 新能源 204 万） | 不含海外本地生产，而分子里包含 → **把比例算高** |
| (c) 中国车企海外总销量（出口 + 海外本地产） | **约 590–640 万辆（估算）** | 与分子口径对齐，但**无任何机构公布过官方汇总数**，是估算 |

(c) 的估算方法：(b) 491 万 + 海外本地产约 100–150 万。后者由单点数据支撑：上汽泰国/印尼/印度三国海外基地产销约 12 万台；比亚迪泰国工厂投产 16 个月累计约 7 万辆；长安泰国罗勇工厂一期年产能 10 万辆、2025 年 5 月单月 2 万台下线。

> 注意：行业里流传的"900 万台"口径**不能**直接当作 (c)，因为它明确包含国际车企中国基地的出口。

### 分子：可自动化的 8 个市场，2025 年中国品牌合计约 47 万辆

| 市场 | 中国品牌销量 | 该国乘用车总量 | 份额 | 数据性质 |
|---|---|---|---|---|

### 比例

| 分母 | 比例 |
|---|---|
| ÷ (a) 832 万 | 5.2–6.1%（偏低，分母被稀释） |
| ÷ (b) 491 万 | 8.8–10.4%（偏高，分母漏记本地产） |
| **÷ (c) 约 615 万** | **6.7–8.6%，中位约 7.5%** |

**最终判断：约 5–10%，最合理的中位估计 7–8%。**

### 压倒性的那个事实

**俄罗斯一个国家 2025 年中国品牌卖了 685,200 辆（份额 51.7%），比这 8 个市场加起来还多。**

### 车企自我披露（另一条路，也不及格）

所有中国车企的月度产销快报**只有集团总出口/海外销量一个数字**：无分国家、无分车型，连分品牌都没有（吉利公布的分品牌是总销量而非海外销量）。蔚来/小鹏/理想**根本不拆海内外**（小鹏港交所公告已逐字确认只有总交付量）。奇瑞未整体上市，无官方结构化披露渠道。载体是交易所 PDF，文件名含不可预测短码。

**为 8 家公司写 8 套 PDF 抓取、每月只为拿 8 个数字，投入产出不成立。** 人工填表方案已被否决——它与本工具"正常月份无需任何人工操作"的定位直接冲突。

## 五、品牌别名坑（如果重启，这块必须先做）

**同一集团/品牌在不同数据源里会被拆成多个独立字符串。已抓到的实锤：**

| 坑 | 出现在 |
|---|---|
| `GEELY` 与 `GEELY MOTOR` **并存为两个品牌** | 荷兰 RDW |
| `GREAT WALL` 与 `GWM` **并存为两个品牌** | 新西兰 NZTA |
| `CHERY` / `OMODA` / `JAECOO` 是**三个完全独立的品牌**，不可假设"奇瑞系 = 一个品牌" | 荷兰、新西兰、西班牙、土耳其 |
| 奇瑞在墨西哥叫 **`Chirey`**，不是国际通用的 Chery | 墨西哥 INEGI |
| `AION` 独立于 `GAC` 单列 —— 只筛 "GAC" 会漏掉埃安全部销量 | 维州、泰国 |
| `ORA` 是普通英文单词，模糊匹配极易误伤，必须精确匹配 | 泰国 |
| 芬兰用 `BYD yhteensä`（芬兰语"合计"）作为品牌汇总行 | 芬兰 Traficom |

**结论：不能用单一品牌名匹配，必须维护「品牌别名 → 标准品牌」映射表，且这张表要按市场分别核实，不能全球共用一套字符串假设。**

其他已确认的写法：BYD 在泰国/维州/新西兰/德国/西班牙均为干净的 `BYD`；MG 在新西兰确认为干净单值（不是 `MG ROEWE` 或 `SAIC MG`）；泰国的车型列是品牌名 + 完整车型名（如 `BYD ATTO 3`、`BYD DOLPHIN STD`）。

## 七、调研方法与已知局限

- 本次调研在 Anthropic 云容器内进行，**出站代理执行组织级白名单**，用 curl 直连测试的 28 个目标域名全部在 TCP CONNECT 层被拒（403）。这是容器通用策略，与具体数据源无关。所有验证改走 WebFetch（经 Anthropic 抓取服务）。
- WebFetch 的限制：遵守目标站 robots.txt；无法解析二进制（ZIP/XLSX/Parquet）；响应体上限约 30MB。因此德国 KBA 的 XLSX、维州的 2024 年 ZIP、马来西亚的 30MB+ CSV 都只验证到"文件存在且结构正确"，**没有取出内部具体数字**。
- **生产环境跑在 GitHub Actions 上，大概率不受容器代理限制**（现有的国内数据源抓取就是这么绕过去的）。但**本次未做验证** —— 如果重启，第一步应该是写一个探针工作流，从 Actions 去访问这几个源，确认能通再投入。
- 中汽协（caam.org.cn）访问不稳定（robots 超时与正常返回交替）；乘联会（cpcaauto.com）直接返回 403。国内协会数据本次主要依赖媒体转载源。

## 八、如果重启，从哪里接上

1. **先写探针工作流**，从 GitHub Actions 访问泰国 DLT、荷兰 RDW、西班牙 DGT、德国 KBA 四个源，把原始返回存进仓库。通了再往下走，不通就到此为止。
2. **先建品牌别名表**，按市场分别核实，不要复用国内的 `mapping.json`。
3. **口径要单独一套**。国内是零售，海外是当地上牌。两者同属"终端"口径，可比性尚可，但**绝不能相加**，也不要提供跨国合计 —— 覆盖率只有 7%，任何合计都会被误读成"海外总量"。
4. **海外的第三维是市场（国家），不是车体类型**。海外源基本不给车体类型，且各国分段口径（B-SUV / C-segment）与国内的轿车/SUV/MPV 对不上，硬套等于无据推断。
5. **车型层可以做**。泰国、西班牙、德国、新西兰、维州都有车型级数据，颗粒度不比国内差。（早期判断"海外不做车型层"是错的，此处更正。）

## 九、数字的可信度分级

写进本文档的数字分三类，引用时请注意区分：

- **主线程亲自验证**：荷兰 RDW 的两个查询结果；泰国 CSV 的表头与 BYD 各行；中汽协 2025 全年出口 832 万辆（已直接读到原文）。
- **子代理实测并给出来源 URL**：泰国/西班牙/马来西亚/新西兰/澳大利亚的 2025 年中国品牌销量；俄罗斯 685,200 辆；各数据源的存在性与结构。
- **估算**：德国、荷兰、爱尔兰、芬兰的中国品牌销量；维州的中国品牌销量（按全国份额折算）；分母 (c)「中国车企海外总销量」。**这些在表格里都已单独标注，不要当作实测数引用。**
