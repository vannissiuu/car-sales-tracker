# 中国汽车销量看板 —— 能用它干什么

在线地址：**https://vannissiuu.github.io/car-sales-tracker/**

数据覆盖 2024 年 1 月至今，逐月、车型级别，每月自动更新，无需任何人工操作。
维度：年份 / 厂商 / 品牌 / 车体类型 / 车型 / 能源类型（燃油·新能源）/ 销量。

**口径说明**：本数据为**零售**口径（约等于乘联会零售），不是批发、不含进口车型。
跟外部数据比之前先对齐口径，不要直接拿这里的数字和"产销"类新闻标题对比。

---

## 典型使用场景

**1. 看头部格局：谁在前面**
年份 + 粒度任选其一（厂商 / 品牌 / 车型 / 能源类型），默认展示当年累计销量 Top 20。
同一件事换三个口径看，结论会不一样——比如「长安」作为厂商和作为品牌，装的不是同一批车。

**2. 拆解一个厂商/品牌的销量结构：是哪几款车撑起来的**
点开任意厂商或品牌（**点名字，不是点前面的勾选框**），右侧抽屉的「统计范围」会列出它名下
全部车型及各自累计销量和占比（不截断）。
用来回答"这个厂商的量集中在几款车上"、"新车有没有接上老车的班"。

**3. 展开一个厂商/品牌下的所有车型走势**
在上一步的抽屉里，「统计范围」那一节点「**查看这些车型的走势 →**」，
自动切到车型粒度并把该厂商/品牌的车型全部上图，跨车体类型（轿车/SUV/MPV 混在一起）。

也可以手动设置：粒度选「车体类型 → 车型」→ 车体类型选「全部车体类型」→ 归属选目标厂商或品牌。

> 注意：在厂商粒度直接勾选「一汽红旗」，得到的是**一条汇总折线**，这是设计如此。
> 要拆成车型必须走上面两条路径之一。

**4. 追单个对象的趋势和同比**
抽屉里有当年逐月柱状图（叠加去年同月做对比）和逐月明细表，每个月都带同比。
用来判断是全年性下滑还是某几个月的坑，以及去年同期基数高不高。

**5. 两个对象贴身对比**
右侧点「清除勾选」清空，再搜索勾选你想比的两个对象，图上就只剩两条线。
看交叉点在哪个月发生、差距是在拉大还是收窄。
勾选状态在切换年份、能源、车体类型、归属时都会保留，可以直接换年份看同一组对象。

**6. 分能源赛道看**
粒度仍然是厂商/品牌/车型，能源类型筛选切「燃油 / 新能源」，看的是**某个阵营内部**谁排在前面。
比如切到「新能源」，就能看新能源阵营里谁领先；同一个厂商在两个赛道上的位置往往完全不同。

**7. 看燃油 vs 新能源的大盘走势**
这跟上一条是**两件不同的事**：上一条是筛选器（在一个阵营内部比排名），这一条是把能源类型
本身当成分析对象。做法：粒度切到「能源类型」，图上就只剩「燃油」「新能源」两条线，
是全国大盘的两条赛道曲线本身。配合「归属」筛选，还可以只看某个厂商/品牌自己的油电结构。

**8. 看能源占比**
在上一条「能源类型」粒度下，鼠标悬停到图上任意月份，悬浮框里除了累计销量还会多显示一个
百分比——占比的分母是当前筛选范围下（车体类型/归属筛选后）该月燃油+新能源两者累计销量的
合计。用来回答"新能源渗透率走到哪一步了"。

**9. 看细分市场**
粒度选「车体类型 → 车型」，再选 SUV / 轿车 / MPV / 运动汽车，
看该细分市场的头部车型、有没有新面孔挤进来。选「全部车体类型」则是不分车体的全国车型榜。

**10. 看集中度**
图表模式切「堆积面积」，再打开「其他」聚合线，
能直观看到头部若干家占了整个盘子的多少、这个比例在往哪个方向走。

**11. 看年度之间的变化（年度推移视图）**
图表区右上角点「按年对比」（切回按月看点同一个按钮，文案会变成「按月累计」），
横轴变成分析对象（按销量从高到低排），同一个对象下并排三根柱子，代表不同年份，
颜色由浅到深表示年份由早到新。历史年份是**全年**实心柱；最新年份因为还没走完，
柱高是**到当前已发布月份为止的同期合计**，柱内还画了一条参考线标出历史年份同一时间段的
位置，所以能直接看出"今年到目前为止跟去年同期比是涨是跌"。
这个视图下对象上限是 10 个（月视图是 20 个）。
**注意口径**：柱子高度一个是全年、一个是同期，不是同一件事，口径标注写在图表上方的
年份图例上，截图外传时记得把这行图例一起带上。

**12. 查某个对象的最新动态**
抽屉里点「查最新」，实时检索该对象近期最值得关注的信息（价格调整 / 新车改款 /
产能 / 渠道 / 舆情 / 财务等），且厂商、品牌、车型三个层级关注的维度不同。
（当前上游检索服务的 API key 待更换，此功能暂时不可用，其余功能不受影响。）

**13. 取数做自己的分析**
点「切换为表格视图」→「下载 CSV」，拿到当前筛选条件下的原始数据，直接进 Excel 或 PPT。
文件名里带年份、粒度、归属、能源，方便事后追溯口径。

**14. 一键复位**
「清除勾选」按钮右侧是「一键复位」，点一下整个看板回到首屏状态（年份、粒度、车体类型、
归属、能源筛选、已勾选对象、图表模式、按年/按月视图全部还原）。
适合"筛选翻乱了想重来"，或者"要给别人演示、先归零"。深色/浅色主题是个人设置，不会被复位。

## 几点使用须知

- **两个数字不一样是正常的**：页面顶部写「累计收录 117 厂商 · 121 品牌 · 895 车型」，
  指的是 2024 年至今**累计出现过**的对象总数；图例上方写「99 个对象（2026年有销量）」，
  指的是**当前所选年份**真正有销量的对象数。全年挂零的对象不进图表，避免一堆贴地的零线。
- **"排名"要看清比较池**。加了车体类型或归属筛选之后，抽屉里的排名是**筛选后池子内**的排名，
  标签会写明，例如「当前排名（一汽红旗 内）」。截图外传前请确认这一行。
- **车型是最小统计单位**，不可再拆；厂商来自数据源原字段；品牌是本工具归并出来的。
  悬停在厂商/品牌的折线或图例上，会提示该口径下具体包含哪些车型——**结论可核对**。
- **能源类型只有燃油 / 新能源两分**，不区分纯电、插混、增程（数据源只到这个粒度，不做推断）。
- **当年数据只到最新已发布月份**，后面的月份不补零，折线在此断开。
- 895 款车型里有 41 款（4.6%）的车体类型是「其他」，销量占比 1.5%，多为微面类，
  这些车不在数据源任一细分榜单中。
- **归属会被自动复位**：切换粒度、或点「清除勾选」时，归属会自动跳回「全部」（车体类型和
  图例搜索框也一起清空）；单独切换年份、能源类型、车体类型时，归属保持不变。
  这是同事最容易被绕晕的地方，操作前留意一下当前"归属"选的是谁。
- 页面支持深色模式和手机访问。
